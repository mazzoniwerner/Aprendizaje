Operaciones Basicas

Las operaciones basicas en Dart permiten realizar calculos matematicos con variables numericas. Puedes declarar variables enteras con int y realizar sumas, restas, multiplicaciones y divisiones. 

int a = 5;
int b = 6;
int c = b + 1;
int d = a + b;

void main() {
  print(c);  // Imprime: 7
}

Bloques de Codigo

Los bloques permiten agrupar codigo y pasar parametros a funciones. Usando String n como parametro, podemos personalizar la salida de nuestras funciones. 

void saludo(String n) {
  print('Hola $n bienvenido');
}

void main() {
  saludo('lucas');
}

// Ejemplo numerico con calculo de IVA
void calcula(double n) {
  n = n * 1.19;
  print('Tu calculo es $n');
}

void main() {
  calcula(5);
}

Funciones

Las funciones en Dart permiten encapsular logica reutilizable. Pueden tener parametros tipados y pueden acceder a variables globales. 

var n = "lucas";
var a = 25;

void nombre() {
  print("mi nombre es " + n);
}

void edad() {
  print("mi edad es $a");
}

void main() {
  nombre();
  edad();
}

// Funcion con parametro y condicional
void pago(num n) {
  if (n >= 500) {
    print("$n es un numero grande");
  } else {
    print("$n es un numero pequeno");
  }
}

Condicionales If/Else

Los condicionales permiten ejecutar codigo basado en condiciones. Dart usa la sintaxis clasica de if/else para controlar el flujo del programa. 

// Sin parametro
int n = 5;

void main() {
  if (n < 10) {
    print('Es menor a 10');
  } else {
    print('Es mayor a 10');
  }
}

// Con parametro
void condicion(int n) {
  if (n < 10) {
    print('Es menor a 10');
  } else {
    print('Es mayor a 10');
  }
}

// Ejemplo calculo de IVA
void iva(double n) {
  if (n <= 0) {
    print("no tuvo ingresos");
  } else {
    n = n * 1.19;
    print("Su iva es: $n");
  }
}

Listas

Las listas en Dart son colecciones ordenadas de elementos. Puedes acceder a elementos por indice y usar metodos como .add() para agregar nuevos elementos. Dart puede inferir el tipo o puedes especificarlo con List<String>. 

var a = ["lucas", "mazzoni"];

void nombre() {
  print(a[0]);  // Accede al primer elemento
}

void apellido() {
  print(a[1]);  // Accede al segundo elemento
}

void agregar() {
  a.add("werner");  // Agrega un elemento
  print(a[2]);
}

void main() {
  nombre();
  apellido();
  agregar();
}

// Tambien puedes especificar el tipo:
// List<String> a = ["lucas", "mazzoni"];

Ciclo For

El ciclo for permite iterar sobre colecciones o ejecutar codigo un numero determinado de veces. Dart soporta tanto el for clasico como el for-in para recorrer listas. 

// For-in con lista de strings
List<String> funcionalidades = ["Usuario", "Pagos", "Perfil", "Notificaciones"];

void main() {
  for (var funcionalidad in funcionalidades) {
    print("Implementando: $funcionalidad");
  }
}

// For clasico con contador
void main() {
  for (var i = 1; i < 10; i = i + 1) {
    print(i);
  }
}

// Sumatoria de una lista
void main() {
  List<num> a = [200, -50, 1000, 0, -10, 500];
  num total = 0;

  for (num i in a) {
    total = total + i;
    print(total);
  }
}

Mapas (Diccionarios)

Los mapas son colecciones de pares clave-valor. Son utiles para almacenar datos estructurados como informacion de usuarios. Accedes a los valores usando la clave entre corchetes. 

void main() {
  var usuario = {
    "Nombre": "Lucas",
    "Edad": 33
  };

  print(usuario["Nombre"]);  // Imprime: Lucas
  print(usuario["Edad"]);    // Imprime: 33
}

Clases

Las clases permiten crear objetos con propiedades y metodos. En Dart, puedes usar constructores abreviados con this.propiedad para inicializar campos facilmente. 

class Usuario {
  String nombre;
  num saldo;

  // Constructor abreviado
  Usuario(this.nombre, this.saldo);
}

void main() {
  var user1 = Usuario("Lucas", 1000);
  var user2 = Usuario("Gabi", 1500);

  print(user1.saldo);  // Imprime: 1000
  print(user2.saldo);  // Imprime: 1500
}
